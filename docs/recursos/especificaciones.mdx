<p style={{ fontSize: '1.15rem', color: '#a0b2bd', marginBottom: '3.5rem', lineHeight: '1.6' }}>
  Guía para navegar y usar la documentación interactiva.
</p>

<p style={{ color: '#a0b2bd', fontSize: '1.05rem', lineHeight: '1.6', marginBottom: '2rem' }}>
  Esta guía te ayudará a utilizar eficazmente la documentación interactiva de las APIs de SPIDI. Cada endpoint incluye 8 partes clave para facilitar tu integración:
</p>

<ol style={{ color: '#a0b2bd', fontSize: '1.05rem', lineHeight: '1.8' }}>
  <li><strong style={{ color: '#fff' }}>Descripción:</strong> Qué hace el endpoint</li>
  <li><strong style={{ color: '#fff' }}>Endpoint:</strong> Método HTTP y URL</li>
  <li><strong style={{ color: '#fff' }}>Ejemplos Request:</strong> Cuerpos de ejemplo para enviar</li>
  <li><strong style={{ color: '#fff' }}>Descripción Request:</strong> Detalle de cada campo</li>
  <li><strong style={{ color: '#fff' }}>Ejemplos Response:</strong> Respuestas esperadas</li>
  <li><strong style={{ color: '#fff' }}>Descripción Response:</strong> Significado de cada campo retornado</li>
  <li><strong style={{ color: '#fff' }}>Sandbox en vivo:</strong> Prueba directa contra el entorno de testing</li>
  <li><strong style={{ color: '#fff' }}>Ayuda códigos:</strong> Tabla de códigos de error con explicación</li>
</ol>
