  Confirmar Pago
</h1>

<p style={{ fontSize: '1.15rem', color: '#a0b2bd', marginBottom: '2.5rem', lineHeight: '1.6' }}>
  Pasa una transacción que estaba en estado PENDING a PAID. Adicionalmente, si la orden fue cancelada (estado CANCELED) antes de la confirmación del POS, emitir esta llamada sobrescribirá la cancelación y confirmará el pago con estado PAID.
</p>

## Code Example

```javascript title="Node.js (Axios)"
const axios = require('axios');
let data = JSON.stringify({
  "authorizationCode": "171599",
  "processCode": "002000",
  "commitAt": "2024-07-29T15:51:28.071Z",
  "amountReference": 100.001,
  "terminalNumber": "98202003219630",
  "trace": "000535",
  "utcDate": "1007151715",
  "cardTypeForRpt": "C",
  "visorMccCard": "MCC",
  "batchNumber": 3
});

let config = {
  method: 'post',
  maxBodyLength: Infinity,
  url: '[https://dev.api.spuntodeventa.com/api/v1/pos-terminals/:serialNumber/transactions/:orderId/commit](https://dev.api.spuntodeventa.com/api/v1/pos-terminals/:serialNumber/transactions/:orderId/commit)',
  headers: { 
    'Content-Type': 'application/json',
    'x-pos-signature': '<FIRMA_HMAC>'
  },
  data: data
};

axios.request(config)
.then((response) => {
  console.log(JSON.stringify(response.data));
})
.catch((error) => {
  console.log(error);
});
