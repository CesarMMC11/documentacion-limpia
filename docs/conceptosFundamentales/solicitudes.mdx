## ¿Qué son las Solicitudes de Pago?

Las **Solicitudes de Pago SPIDI** permiten emitir invitaciones de pago preconfiguradas (enlaces compartibles por email, WhatsApp, SMS) con monto e identificación. Son ideales para **pagos directos, recurrentes, suscripciones o procesos programados**.

## Flujo de una solicitud de pago

* Se crea por API **cuando se desee**, programada o manual, unitaria o masiva
* Requiere **monto** (en Bs o moneda de referencia) y `internal_reference`
* SPIDI genera hash único, status: `pending`
* **Duración configurable**: fecha de vencimiento o sin expiración
* Estados: `pending`, `paid`, `expired` — un pago fallido **no termina la sesión**
* Si la moneda no es Bs, el monto se **ajusta a la tasa BCV vigente** al acceder
* Permite crear **múltiples solicitudes (1..N) en un mismo request**

## Relación con las Paradas SPIDI

Para suscripciones y pagos recurrentes, las **Paradas** son el acompañante ideal. Cada cliente tiene una Parada única donde consulta y paga todas sus solicitudes.
