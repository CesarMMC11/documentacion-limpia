## Propósito

Los **webhooks** permiten recibir notificaciones automáticas de eventos relevantes sin consultas periódicas. SPIDI notifica en tiempo real sobre pagos completados, sesiones fallidas o expiradas.

## Seguridad: ¿Por qué validar la firma?

Sin validación, un atacante podría enviar JSON falso a tu endpoint simulando un pago exitoso. Con HMAC-SHA256, tu servidor calcula el hash del body recibido y lo compara con <code style={{ backgroundColor: '#052a20', color: 'var(--ifm-color-primary)' }}>SPIDI-Signature</code>. Si no coinciden → <code style={{ backgroundColor: '#052a20', color: 'var(--ifm-color-primary)' }}>401 Unauthorized</code>.

## ¿Por qué validar el timestamp?

Previene **replay attacks diferidos**. Si un atacante reenvía un paquete viejo días después (cuando la Idempotency-Key ya expiró de tu caché), el timestamp fuera de rango (>5 min) permite rechazarlo.

## Recomendaciones para Receptores

* Validar firma y timestamp antes de procesar
* Responder <code style={{ backgroundColor: '#052a20', color: 'var(--ifm-color-primary)' }}>200 OK</code> en menos de 2 segundos
* Procesar en background si se necesita lógica adicional
* Registrar <code style={{ backgroundColor: '#052a20', color: 'var(--ifm-color-primary)' }}>Idempotency-Key</code> para evitar reprocesos
* Endpoint dedicado: <code style={{ backgroundColor: '#052a20', color: 'var(--ifm-color-primary)' }}>POST https://miapp.com/webhooks/spidi</code>
