## ¿Qué es un Acuerdo de Pago?

Un **Acuerdo de Pago** es un contrato digital que establece las reglas de distribución y liquidación para las transacciones. Funciona como un "contrato inteligente" que define:

* **Cómo se dividirán los fondos** entre el comercio propietario y sus partners o distribuidores
* **A qué cuentas bancarias** se dirigirán los pagos según el banco de origen del pagador
* **Qué medios de pago** acepta el acuerdo (débito inmediato, criptomonedas, pagos móviles)
* **Las reglas de liquidación** que optimizan la distribución de fondos

## Funcionalidades Principales

### 🎯 Distribución de Pagos (Split Payment)
* **Split Fijo (FIXED)**: Porcentajes de distribución predefinidos y constantes
* **Split Dinámico (SESSION)**: Configuración flexible en cada sesión de pago
* **Múltiples Receptores**: Distribuir fondos entre el comercio y múltiples partners
* **Validación Automática**: Suma de porcentajes = 100%

### 🏢 Liquidación Bancaria Inteligente
* **Reglas por Banco de Origen**: Dirige pagos a diferentes cuentas según el banco del pagador
* **Cuenta por Defecto**: Configuración de respaldo para bancos no especificados
* **Optimización de Costos**: Reduce comisiones bancarias
* **Soporte Multi-Banco**: Compatible con todos los bancos venezolanos

### 💳 Medios de Pago Configurables
* **Débito Inmediato**: Pagos directos desde cuentas bancarias
* **Criptomonedas**: Bitcoin, Ethereum y otras via Binance Pay
* **Pagos Móviles**: Integración con sistemas de pago móvil

## Tipos de Acuerdo

* **Tipo "Button"**: Para pagos iniciados por el comercio. Configuración simple, ideal para e-commerce.
* **Tipo "Request"**: Para solicitudes de pago enviadas al cliente. Mayor flexibilidad.

## Flujo de Trabajo Típico

1. Creación del Acuerdo: define reglas de distribución y liquidación
2. Configuración de Split: establece división de fondos
3. Definición de Reglas Bancarias: configura liquidación inteligente
4. Activación: el acuerdo queda listo para procesar
5. Uso en Sesiones: se aplica automáticamente en cada pago
6. Monitoreo: seguimiento de transacciones y distribuciones
