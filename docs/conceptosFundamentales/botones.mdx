## ¿Qué son los botones de pago SPIDI?

Los **Botones de Pago SPIDI** permiten que tus usuarios paguen desde **cualquier banco venezolano o Binance Pay (USDT)** sin salir de tu plataforma. Habilita todos los medios de pago inmediatos: **débito bancario, Pago Móvil y Binance Pay**, con **liquidación directa en bolívares**.

## Tipos de botones

* 🖥️ **Botón SPIDI para Web**: para sitios o aplicaciones web, pago en el navegador.
* 📱 **Botón SPIDI para App**: para apps móviles (Android, iOS, híbridos), con deeplinks o WebView.

## Base común de todos los flujos

* Sesión de pago creada via API con monto e identificación
* SPIDI genera un **hash único**, status inicial: `pending`
* Vida útil: **10 minutos**
* Estados: `pending`, `paid`, `failed`, `expired`
* Estado `failed` termina la sesión definitivamente
* No se permiten operaciones cerca de medianoche

## Botón SPIDI para Web

### Estrategia 1 — Misma pestaña (recomendada)
**Flujo:** Tu web → SPIDI (misma pestaña) → Redirección automática a tu web

1. Usuario hace clic en botón de pago
2. Tu backend crea sesión con `success_url`, `failure_url`, y opcionalmente `webhook_url`
3. SPIDI responde con `session_id`
4. Tu frontend construye `payment_url` → `{url_base}/{session_id}`
5. Rediriges con `window.location.href`
6. Tras pago, SPIDI redirige a `{success_url}?session_id=sess_abc123`
7. Tu app lee el `session_id` y consulta endpoint de estado para validar

**Flujo:** Tu web → Nueva pestaña con SPIDI → Usuario cierra pestaña → Regresa a tu web

Dejar `success_url` y `failure_url` vacíos. Usar polling, botón "Ya pagué", o webhooks.

## Botón SPIDI para App

### Estrategia 1 — Deeplink (recomendada)
Configura `success_url: miapp://pago-exitoso` y `failure_url: miapp://pago-fallido`. SPIDI redirige al deeplink con `session_id`.

### Estrategia 2 — Captura de cambio de URL
Detecta cambio de URL dentro del WebView, cierra WebView, muestra pantalla nativa.

## Comprobante y fidelización

El endpoint de status devuelve una **URL del comprobante de pago**. Mostrar este enlace mejora la transparencia y en el comprobante SPIDI invita al usuario a registrarse, lo que **reduce comisiones** a mediano plazo.
