## Descripción

Permite autenticar un usuario en el sistema SPIDI. El token JWT retornado debe incluirse en el header <code style={{ backgroundColor: '#052a20', color: 'var(--ifm-color-primary)', padding: '2px 6px', borderRadius: '4px' }}>Authorization: Bearer &#123;token&#125;</code> de todas las requests posteriores.
